Fast fertig

Ab jetzt öffnen sich PDFs, die Sie im Browser anklicken, direkt in PDFMy – zum Lesen, Unterschreiben, Schwärzen, Ablegen. Die Datei bleibt dabei auf Ihrem Gerät, es gibt keinen Upload.

Dafür braucht die Erweiterung einmalig Ihre Erlaubnis, PDFs von Webseiten zu laden. Der Browser fragt gleich nach.

So benutzen Sie PDFMy

  1. PDF anklicken – sie öffnet sich in PDFMy statt im Adobe- oder Browser-Viewer.
  2. Rechtsklick auf einen Link → „In PDFMy öffnen“ – auch wenn das automatische Öffnen aus ist.
  3. Symbol „PDFMy“ oben rechts (ggf. unter dem Puzzle-Symbol anheften): automatisch öffnen an/aus, aktuelle PDF übernehmen.
  4. Wollen Sie eine PDF doch im alten Viewer sehen: im Browser auf „Zurück“ klicken.

Datenschutz

Die Erweiterung lädt nur die PDF, die Sie öffnen, und übergibt sie direkt im Browser an pdfmy.de. Sie sendet keine Daten an Mentor Group oder Dritte, speichert keinen Verlauf und enthält keine Statistik. Den Zugriff auf Webseiten können Sie jederzeit im Symbol „PDFMy“ wieder ausschalten.
