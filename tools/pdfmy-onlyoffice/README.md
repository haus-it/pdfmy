## Overview

Open the current document as a PDF in [PDFMy](https://pdfmy.de) – edit, sign, redact, compress, convert to PDF/A or e-invoice. PDFMy is a free PDF editor that runs entirely in the browser: the PDF is created by your own ONLYOFFICE Docs server and handed directly to PDFMy in your browser. Nothing is uploaded to third parties.

The plugin is called **PDFMy** in the interface and is offered by Mentor GmbH, Paderborn, Germany.

## How to use

1. Open a document, spreadsheet, presentation or PDF in ONLYOFFICE Docs.
2. Open the **Plugins** tab and click **PDFMy**.
3. Click **Open in PDFMy**. A new browser tab opens PDFMy, asks once whether to accept the file from your ONLYOFFICE server and loads the PDF.

Allow pop-ups for your ONLYOFFICE site if the browser blocks the new tab.

## Supported editors

Document, spreadsheet, presentation and PDF editors of ONLYOFFICE Docs 7.4 or later (Docs Community/Enterprise/Developer, DocSpace, Workspace). The interface is available in 40 languages.

In the ONLYOFFICE desktop editors, plugins cannot obtain a PDF of the document; there the plugin points to printing with the “PDFMy” printer from [pdfmy Scan](https://pdfmy.de/scanner.html).

## Privacy

The plugin sends no data to Mentor GmbH. The PDF goes from your ONLYOFFICE server to the PDFMy page in your browser via `postMessage`; PDFMy processes it locally. See the [privacy policy](https://pdfmy.de/datenschutz.html) and [terms of use](https://pdfmy.de/nutzungsbedingungen.html).
